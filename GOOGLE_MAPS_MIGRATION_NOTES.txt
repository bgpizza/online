BAKE & GRILL — GOOGLE MAPS IMPLEMENTATION NOTES
Updated: 19 November 2026

The current app.js implementation uses the Google Maps JavaScript API loader.
Confirmed code paths:
- google.maps.importLibrary("routes") and Route.computeRoutes() for driving routes.
- google.maps.importLibrary("marker") and AdvancedMarkerElement for the draggable delivery pin.
- google.maps.Geocoder() for address geocoding and reverse geocoding.

The current app.js no longer contains Places Autocomplete Data API, Place.searchByText, PlacesService, AutocompleteService or a Places library loader. Historical notes describing Places-based typeahead are not a reliable description of the current production code.

Required Google Cloud APIs for the current app.js:
1. Maps JavaScript API
2. Routes API
3. Geocoding API

Production host: https://bakeandgrill.in
Maps browser-key restriction: HTTP referrer https://bakeandgrill.in/*
Add www or github.io only where a real production page is still served from that host.

The existing Maps browser key has been exposed in public client code and in chat. Create and restrict a replacement key, test all map and route flows, update GOOGLE_MAPS_API_KEY in app.js, deploy, and then disable/delete the old key. The browser key is not a secret, but its restrictions are required to limit misuse.

App Check and Firestore authorization are separate controls. Maps key restrictions protect Maps API quota/billing; Firestore Security Rules and App Check protect Firebase data/services.
