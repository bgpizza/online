BAKE & GRILL PWA

1. Upload all files to the same GitHub Pages /online folder.
2. Keep assets/ folder and its files.
3. Open index.html over HTTPS (GitHub Pages is HTTPS).
4. On Android Chrome/Brave use the browser menu -> Install app / Add to Home screen.
5. Firebase config is already included in firebase-config.js.

The service worker caches the local app shell for faster repeat loads. Firebase/WhatsApp network calls continue online.
