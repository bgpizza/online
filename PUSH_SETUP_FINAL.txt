BAKE & GRILL CUSTOMER ORDER STATUS PUSH - V27

Customer website changes included:
- Firebase Messaging compat SDK loaded on customer pages.
- Customer can tap “Enable order status notifications” on the order tracking section.
- Permission is requested only after that tap.
- FCM token is saved against the active order in Firestore collection pushTokens.
- Cloud Function notifyOrderStatus sends status changes to that order's registered token.
- Background service worker displays order status notifications.

REQUIRED ONE-TIME FIREBASE DEPLOYMENT (must be done by project owner):
1. In Firebase Console > Project settings > Cloud Messaging, confirm Web Push certificate/VAPID key matches the public key in notifications.js.
2. Confirm Cloud Messaging API is enabled and the Firebase project is on Blaze billing for Cloud Functions.
3. From this folder run: firebase login
4. Run: firebase use bake-grill
5. Run: cd functions && npm install && cd ..
6. Run: firebase deploy --only firestore:rules,functions

CUSTOMER TEST:
1. Deploy the website to GitHub Pages over HTTPS.
2. Place a test order, open its tracking section/page.
3. Tap “Enable order status notifications” and Allow.
4. Confirm Firestore > pushTokens has a document with this orderId.
5. Change the order status from Master Panel.
6. Customer device should receive a push notification.

IMPORTANT LIMITATIONS:
- A ZIP cannot deploy Cloud Functions or Firestore Rules automatically. The Firebase deploy command above is required.
- Customer must grant notification permission. Browser/device notification settings must allow notifications.
- Web Push support varies by browser/device; use Chrome or Edge on desktop/Android, or an installed supported PWA on iOS.
- VAPID key in notifications.js is a public key, not a server secret. Verify it matches Firebase Console before production use.
